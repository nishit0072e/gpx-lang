1. OBJECT-ORIENTED STRUCT METHODS & RECEIVER SYNTAX
--------------------------------------------------------------------------------
Goal: Provide clean object-oriented syntax sugar on top of zero-overhead C structs.
* Method declarations with pointer or value receivers:
    fn (self: *Vector) add(other: *Vector) -> Vector { ... }
* Method invocation syntax:
    vec.add(&other)
    player.move(10, 20)
* Associated functions / constructors:
    Vector::new(x, y)
* Full transpilation to high-performance C function dispatch:
    Vector_add(&vec, &other)

2. DATA STRUCTURES & ALGORITHMS (DSA) STANDARD SUITE
--------------------------------------------------------------------------------
Goal: Comprehensive, production-grade standard library for algorithms & collections.
* Dynamic Arrays & Lists (<list.gpx>):
    - Growable contiguous vector: list_create, list_push, list_pop, list_get, list_free
    - OO syntax: list.push(item), list.pop(), list.len()
* Linked Lists (<linkedlist.gpx>):
    - Singly and doubly linked lists with node manipulation, insert, remove, traverse
* Stacks & Queues (<stack.gpx>, <queue.gpx>):
    - LIFO Stack: push, pop, peek, is_empty
    - FIFO Queue & Circular Ring Buffer: enqueue, dequeue, peek, is_empty
* Hash Tables & Maps (<hashmap.gpx>, <hash.gpx>):
    - Key-value hash map with open addressing / robin hood hashing
    - Hashing algorithms: FNV-1a, MurmurHash3, djb2
    - Operations: map.set(key, val), map.get(key), map.has(key), map.delete(key)
* Trees & Binary Search Trees (<tree.gpx>):
    - BST and AVL self-balancing tree implementations: insert, search, min, max
    - Tree traversals: in-order, pre-order, post-order, level-order
* Graphs & Pathfinding (<graph.gpx>):
    - Adjacency list / matrix representations
    - Algorithms: Breadth-First Search (BFS), Depth-First Search (DFS), Dijkstra's shortest path
* Sorting & Searching Algorithms (<algorithms.gpx>):
    - Sorting: Quicksort, Mergesort, Heapsort, Insertion sort, Bubble sort
    - Searching: Binary search, Linear search
* Storage Management (<memory.gpx>):
    - Heap memory tracking, memory pool allocators, arena allocators

7. GENERICS & PARAMETRIC POLYMORPHISM
--------------------------------------------------------------------------------
Goal: Type-safe, reusable data structures and algorithms with zero runtime overhead.
* Generic functions:
    fn identity<T>(val: T) -> T { return val; }
    fn max<T>(a: T, b: T) -> T { ... }
* Generic structures & containers:
    struct Stack<T> { data: [T; 100], top: int }
    struct Pair<A, B> { first: A, second: B }
* Compile-time monomorphization pass producing optimized specialized types.

Goal: Expressive, exhaustive compile-time branching and tagged unions.
